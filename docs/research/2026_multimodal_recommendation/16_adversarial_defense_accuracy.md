# 有意图文操纵下的促销防御取舍与训练污染曝光残余

## P25 协调式对抗训练降低攻击收益，但未消除残余促销与准确率代价

- **问题、条件与影响**：当攻击者在推理期针对冷门物品的图文特征实施有目标的促销扰动时，更强防御和干净数据上的排序质量不能在所测设置中同时无代价改善。不同于 P06 的随机错配/低清输入，这里有明确攻击目标、攻击预算以及防御目标。
- **证据**：UAT-MC §5.2/Table 2，Baby–VBPR：无防御 PGD+协调攻击的目标 Hit@50 从 0.667% 升到 4.143%；UAT-MC 从 0.621% 升到 1.544%，数值上已明显降低攻击效果但仍有残余。干净 Recall@10 为无防御 0.0503、UAT-MC 0.0476。§5.3/Fig.6 明确呈现推荐质量与攻击收益的取舍。
- **已经缓解/仍存不足**：作者已处理未知攻击目标与跨模态梯度不协调，不能把这两项原始动机再算新痛点。剩余只限定其 VBPR/MMGCN、三份 Amazon 数据及所测预算，不推断所有防御或实际平台必然失效。残余攻击和准确率代价作为同一取舍问题计一次。
- **判断类型**：作者明确指出 + 实验支持（论文报告；本轮未实施攻击、未训练或复现）。
- **官方状态**：[IJCAI 2026 Main Track 正式全文页](https://ijcai.org/proceedings/2026/347)，3124–3132，[DOI](https://doi.org/10.24963/ijcai.2026/347)。沿用首轮口径，作为明确标注的扩展来源，不冒称其他级别。
- **官方仓库及代码边界**：[gmXian/UAT-MC](https://github.com/gmXian/UAT-MC)。实际检查提交 `8694273e7667782baf731835e9e2180245980507`（2026-05-02）仅有 README；[L3–16](https://github.com/gmXian/UAT-MC/blob/8694273e7667782baf731835e9e2180245980507/README.md#L3-L16)明确源码、脚本和数据尚待发布。因此没有已核验实现文件/类/函数，不能说已检查了该方法的训练实现。

## 归并决定

这是有意攻击下的防御—效用问题，不与 P06 的输入质量现象或 P10 的表示一致性强度合并。虽然论文也使用“对齐”，其对齐对象是对抗扰动梯度，不是用表征相似度改善常规推荐。P25不并入P06/P10；与下述P26同文但分别计数。

## P26 跨模态训练污染可在常规过滤后保留定向曝光

- **问题与条件**：VENOMREC 的灰盒训练污染设置下，少量受控用户及协同图文内容改变目标物品曝光；常规排序质量接近未过滤状态，不代表定向操纵消失。
- **正式证据**：[ICML 2026 PMLR306 正式论文页](https://proceedings.mlr.press/v306/guan26b.html)，37417–37433。采用正式版而非早期三数据集摘要。§5.5/Table 5、Appendix A.3，Clothing、0.1%受控用户：Few-/Zero-Shot ER@20 无防御 .7170/.7317，AE Filter .7174/.7280，LexNorm .7100/.6743，Freq-Rarity .6820/.6357；这些过滤未消除曝光，同时所列HR/NDCG接近无防御值。
- **已缓解/残余**：过滤分别处理历史异常、文本规范化/稀有词，但限定实验仍有残余。本文研究攻击而不是宣称已提供完整防御；不推广到全部安全机制。
- **类型/边界**：实验支持、作者明确指出。图像侧是 projected patch features 扰动，不声称实际原像素上传攻击全链路已被验证；本轮无攻击或训练执行。
- **代码**：[官方 VenomRec](https://github.com/GuoweiGuan666/VenomRec)，提交 `076ce68a37692e1166367947c0e1c5aeaaff4f26`。[`masked_pgd_image` L12–71](https://github.com/GuoweiGuan666/VenomRec/blob/076ce68a37692e1166367947c0e1c5aeaaff4f26/attack/ours/dcip_ieos/image_perturbation.py#L12-L71)界定所查特征层输入；[`_build_ae_feature/_apply_ae_defence` L438–549](https://github.com/GuoweiGuan666/VenomRec/blob/076ce68a37692e1166367947c0e1c5aeaaff4f26/attack/ours/dcip_ieos/poison_pipeline.py#L438-L549)定位历史统计过滤。未核验LexNorm/Freq-Rarity一一对应函数，不猜名称。

**为何同文分项**：P25是在推理期改特征后的防御—干净质量取舍；P26是在训练期协同污染后的定向曝光残余。共同是恶意图文操纵，但权限、发生阶段和结果不同，因此保留两项；都不等价于随机内容损坏 P06。
