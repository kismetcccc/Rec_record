# 频域平滑深度过大时，有用细节可能随噪声被压掉

## P09 平滑收益依赖数据，深分解并非单调更好
- **问题、条件、影响**：在用小波近似分量过滤特征时，增加分解层数会进一步去除细节，某些数据上的排序表现反而下降。
- **证据**：MMWave IV-C/Fig.6，较深分解损害 TikTok，而 Sports 受益。不能把单数据现象泛化为频域方法必然有害。
- **已处理/剩余**：MMWave 已以波段处理模态冗余和抑制，仍有数据相关的滤波深度边界。
- **类型**：实验支持；代码观察定位细节置零机制。
- **代码**：[官方仓库](https://github.com/kennethorq/MMWave)，[`wavelet_extraction` L308–338](https://github.com/kennethorq/MMWave/blob/51e761d6dc18125aa7d1a58764de2061bfdb457c/src/models/mmwave.py#L308-L338) 保留近似系数、置零细节系数再重建；不据此声称所有高频都是有用偏好。
- **正文**：[作者全文](https://arxiv.org/html/2610.16229v1)。

本项是模态内部特征删除，不是模态缺失或邻居扩张，独立保存。
