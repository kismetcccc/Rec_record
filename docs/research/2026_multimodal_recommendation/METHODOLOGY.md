# 检索、证据与计数规则

核验日期：2026-11-02。论文时间窗口：2026-01-01 至该日期。

## 范围与发表状态

研究对象是使用用户交互以及物品图像、文本等内容的推荐。包含非序列、序列和明确依赖交互的生成式推荐；排除与推荐无直接关系的通用多模态任务。

论文进入正式证据池须有 2026 年出版或官方录用证据。发表年份与 arXiv 首次上传年份分开：2025 年预印本、2026 年正式论文可以纳入；2026 年上传、尚无正式录用的论文不冒充已发表工作。会议已录用而尚未举办时，只称已录用。出版社终稿和作者修订稿不默认相同。

检索优先覆盖 SIGIR、WWW、KDD、AAAI、ACM MM、ICDE、ICLR、ICML、NeurIPS，以及 TKDE、TOIS、TMM 等相关高水平来源。RecSys 属推荐系统专门会议；CIKM、WSDM、IJCAI、TORS、Information Fusion 等扩展来源逐篇注明实际 venue/track，不把所有来源笼统称为同一级“顶会顶刊”。Short、Applied、Workshop 与正式长文分别标注。没有检索结果不表示该 venue 没有相关论文。

## 执行顺序

1. 以论文题名、年份、venue、官方仓库为检索线索；综述和第三方列表只用于发现候选。
2. 对照会议程序、出版社元数据、作者主页/论文和官方仓库确认身份及状态。
3. 阅读正文的假设、分析、消融、敏感性实验、限制章节；检查可访问的官方实现。
4. 收集具体问题，再比较对象、成因、环节、条件和影响；同一问题汇总证据，有共同基础但仍不同者在同文档分子项。
5. 将无法确认的论文状态、缺少全文的动机、尚无法判定的代码风险单列，排除出确认数量。

## 判断标签

- **作者明确指出**：作者在正文中明确陈述限制或现象；仍标明其声明边界。
- **实验支持**：存在指定表格、图或分析；数字是论文报告，本轮没有重新训练复现。
- **代码观察**：静态阅读指定版本实现支持。文件定位尽量固定提交 SHA；未查看的类/函数不推测。
- **推断**：由现有证据推导，明确条件，不与作者结论混淆；不足以确认者移入待核验清单。

缺少某个模块、未报告某个实验或只在少数数据集测试，本身不构成已确认缺陷。代码分支或数学条件支持的实现边界可以记录，但不能凭它声称已发生 OOM、论文结果失效或真实部署普遍失败。

## “痛点”与“研究空白”的区别

本记录计数的是**有证据、在明确条件下成立的问题**，不是声称同样数量的全新未解决研究空白。每项区分现有方法已处理的部分和证据仍能支持的剩余问题。仅有引言动机而没有残留证据，不列入确认项。

不同论文的相同问题只计一次。共享问题基础不代表两者等价：同一文档内子项仍各有独立对象或成因时分别计数。代码发布障碍、论文实现一致性与模型研究性能问题分别标明，不能混算成同一种模型缺陷。

## 仓库及操作边界

首轮开始时 GitHub 返回空仓库，未发现已有研究目录。使用用户指定的默认目录。为建立可分支的初始提交，仅在默认分支初始化研究说明；详细研究记录保存于独立分支。不覆盖既有文档，不修改模型、训练器、数据处理、评估器、配置，不运行训练，不创建 Skill。

本轮只进行文献检索、静态源码核验及 Markdown 整理；没有模型设计、模块推荐或实验方案。检索具有覆盖限制，不宣称穷尽整个领域。
